# 赛博绿竖版 · 设计规范（动态图形版）

## 色板

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#060807` | 底色（近黑偏绿） |
| `--g` | `#22F59B` | 主色：荧光薄荷绿。描边、图形、高亮 |
| `--g-deep` | `#0FA86E` | 绿渐变暗端 |
| `--cyan` | `#2DE6E0` | 少量光斑、进度条尾端 |
| `--ink` | `#FFFFFF` | 字幕、标题 |
| `--mute` | `#7E8A84` | 英文副标、HUD 读数 |

画面只用"黑 + 绿 + 白"。图表纸卡可用深红折线（`#8B1E2B`）作对比色。

## 空间层次（由远到近）

1. **远景**：径向绿色底光（缓慢漂移）+ 透视网格隧道（地板/天花板向地平线收束，横线持续向镜头推进）+ 远处尘点。整层做 **中心清晰、四周模糊** 的景深处理，然后叠加失焦光斑。
2. **平面网格**：极淡 54px 网格，只在画面中心可见，随机位轻微视差。
3. **场景层**：放在 3D 透视里——每个场景有缓慢的推镜（scale 1→1.05）和左右摇镜（rotateY ±2.4°，相邻场景方向相反），远景随摇镜产生视差。
4. **近景**：大颗失焦光斑和发光尘粒从镜头前飘过。
5. **镜头**：暗角 + ffmpeg 胶片颗粒。
6. **HUD**（永远清晰）：顶部话题/频道/进度条、REC 闪烁与时间码、两侧刻度导轨、底部字幕。

## 版面（1080×1920）

```
   0–200    顶栏（话题标签 / 频道名 / 进度条）
 200–240    HUD 读数行
 220–1440   场景区（主图形居中略偏上）
1480–1640   字幕 64px 白粗体
1660–1920   平台 UI 安全区（只有背景）
```

左右安全边距 72px，两侧导轨在 28px 处。

## 动效语法

- **转场**：新场景从景深里推出（translateZ -520→0、模糊 14→0），旧场景冲向镜头（translateZ +480、模糊）并淡出，两者重叠 0.45s，切点一记绿色闪光。
- **入场**：元素按 0.15–0.3s 依次进入——卡片弹出（回弹），条形左→右擦出，标题上浮去模糊，线条先画出路径再有数据包跑动，引语逐字打出，数字从 0 滚动计数。
- **常驻运动**（场景里永远有东西在动）：HUD 环正反旋转、地球自转+飞线、雷达扫描、吸引子轨迹生长、流线漂移、数据包循环、波纹扩散、扫描线、图表游标往返读数、3D 板旋转、故障闪烁（偶发）。
- 一个场景的主图形占画面 40–60%；文字只做标签。

## 语义 → 图形

| 讲什么 | 用什么 |
|---|---|
| 全球/网络/覆盖 | `globe` |
| 探测/监控/感知 | `radar` |
| 混沌/不可预测/蝴蝶效应 | `lorenz` |
| 流体/气流/湍流/数据洪流 | `flow` |
| 信号/声音/叠加态/频率 | `wave`、`bars` |
| 穷举/暴力计算/二进制 | `matrix` |
| 增长/放大/失控 | `curve`、`number` |
| 层级/分区/架构 | `layers` |
| 步骤/管线 | `flow`（kind） |
| 中心系统与输入 | `hub` |
| 冲突/不兼容 | `vs` |
| 数据/证据 | `card` + chart |
